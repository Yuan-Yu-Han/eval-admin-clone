使用说明

基本流程

  1. Cases — 管理评测用例。每个用例包含多轮对话（用户输入 + 期望工具），支持新增、编辑、启用/禁用、分组筛选、CSV 导出。
  2. Runs — 启动评测运行。勾选用例后点击"启动运行"，系统会通过 WebSocket 真实调用 AI 管线，逐轮执行并比对工具调用结果。
  3. Mock — 配置 Mock 数据。评测运行时外部 API（车辆查询、权限等）会被 Mock 拦截，这里管理各接口的 Mock 返回值。
  4. Prompt — Prompt 草稿编辑。修改 Prompt 后可在下次运行中生效，用于 A/B 对比不同 Prompt 的效果。

结果查看

  • 点击 Run 进入详情，查看每个用例的 PASS/FAIL、LLM 回复、SkillResult、HintsInfo。
  • 支持按 全部 / PASS / FAIL / 有问题 筛选，阅读模式提供卡片式大字体阅读。
  • 点击轮次中的"查看调试信息"可弹窗查看 SkillResult 和 HintsInfo 的完整 JSON。

对比功能

  • 对比跑说明：对比跑不是自动优化器，它检查同一个 case 在当前 Run 和基线 Run 之间发生了什么变化。
  • 选择基线：在 Run 详情顶栏的"对比基线"下拉框中选择一个历史 Run，基线数据会被加载缓存。
  • 单用例对比：选好基线后，点击任意用例的"对比"按钮，直接进入全屏对比导航视图。
  • 对比模式：点击顶栏"对比模式"按钮，进入逐用例浏览的对比导航。
  • 导航操作：
    • ← / → 方向键或按钮切换上一个/下一个用例
    • F 键快速标记/取消"有问题"
    • Esc 退出对比模式
  • 对比视图展示：PASS/FAIL 是否变化、actualTool 是否变化、LLM 回复是否变化、SkillResult 是否变化、HintsInfo 是否变化。
  • 适合优化 Prompt、路由规则、结果渲染和 Mock 配置；不判断数据库数字是否真实正确。
  • 基线无对应用例时，左侧展示当前结果，右侧提示"基线无此用例"，可继续翻页。
  • 支持随时"换基线"切换到其他 Run。

其他功能

  • 标记有问题：对可疑用例标记"待查"，方便后续筛选复查。
  • 评论：可对每个用例添加评论备注。
  • 下载 CSV：导出当前 Run 的全部结果为 CSV 文件。
  • 停止运行：运行中的评测可随时停止。
  • 重跑：可重新运行已完成的评测。
